## 🚀 What I'm building on the side

### ⚡ [Savergy](https://savergy.pk) &nbsp;<sub>`MVP / beta`</sub>
An AI-powered PWA that helps Pakistani households avoid electricity bill **slab jumps** — the costly per-unit price increases that hit when usage crosses a threshold.

- 🧾 **OCR bill parsing** to read and digitize utility bills automatically
- 📊 Daily consumption tracking with appliance-level load calculations
- 🔮 **AI-based bill estimation** that predicts your end-of-cycle cost
- 🔔 Proactive push notifications **before** you cross into a higher-cost slab

`Next.js` `Python` `OpenAI API` `Firebase` `Vercel`

### 🤝 ShiftSnap &nbsp;<sub>`MVP / beta`</sub>
A production-ready, on-demand **hospitality staffing marketplace** for the Australian market — connecting venues with workers to fill shifts in real time. Built as a full-stack **Turborepo monorepo** spanning mobile, web, and admin, covering **61 screens**.

**Architecture & platform**
- 📱 **React Native + Expo** (iOS & Android) and **Next.js 14 App Router** (web & admin)
- 🟥 **NestJS** TypeScript REST API deployed on **Google Cloud Run**
- 🔥 Mixed serverless + containerised backend — Firebase Cloud Functions, Firestore real-time DB, Firebase Auth with custom role claims, and FCM push notifications

**Core engineering**
- 💳 **Stripe Connect** marketplace payments — escrow, multi-party fee routing, webhook signature verification, dispute handling
- 📍 GPS **geofence validation**, real-time shift timing engine, and distributed auto-assignment locking
- ⭐ Two-way **Trust Score** reputation system — business logic enforced server-side with zero client trust
- 📈 Designed for horizontal scale **from MVP to 1M+ users** using Upstash Redis, Firestore compound indexes, and Cloud Pub/Sub event bus

`React Native` `Expo` `Next.js 14` `NestJS` `TypeScript` `Firestore` `Cloud Run` `Stripe Connect` `Turborepo` `Redis`
